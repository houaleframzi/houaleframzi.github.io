Biography

Dr. Ahmed Ramzi Houalef holds a Doctorate in Computer Science from Université Bourgogne Europe (DRIVE Laboratory). His doctoral research was conducted within the framework of the European project OPEVA (OPtimization of Electric Vehicle Autonomy, Horizon Europe / KDT JU), focusing on data-driven models, reinforcement learning, and distributed AI algorithms applied to modern intelligent transportation systems, connected electric vehicles (EVs), and smart energy grids.

Open-Source Repositories & Hardware Engineering

GitHub Repositories (@houaleframzi)

ChargeTrek Python

Visual RL framework turning EV charging into an Atari-style learning game. Agents learn optimal charge/discharge strategies directly from pixel-based state encodings.

DWCL-RL-CARLA Python / CARLA

A deep reinforcement learning environment in CARLA simulator optimizing Dynamic Wireless Charging Lane (DWCL) usage with DQN, realistic vehicle maneuvers, and battery models.

6G Handover DDQN Python

Double Deep Q-Network implementation for optimizing seamless handover decisions in high-speed 6G vehicular communication environments.

RUT Port Scanner Shell

Custom port scanner built for Teltonika RUT950 dual-SIM 4G industrial Wi-Fi router embedded network monitoring.

Hardware & IoT Engineering Projects (Hackster.io @ramamzi31)

Talking Gloves for Deaf People

Sign language translation wearable glove using gyroscopes, accelerometers, flex sensors, and microcontroller classification.

Wearable Sign-to-Text / Speech

Arduino Nano and HC-05 Bluetooth wearable system with MPU-6050 paired with a custom Android app for real-time speech synthesis.

Wireless Laser Data Transmission (LiFi)

LiFi laser communication system transferring optical binary text key codes between Arduinos via solar cell detection at 100 baud.
